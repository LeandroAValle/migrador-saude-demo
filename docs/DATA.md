# Dados e indicadores

Todas as chaves, unidades e respostas são fictícias. Não há nome, CPF, CNS, prontuário, diagnóstico ou atendimento de pessoa real.

| Entidade | Papel ilustrativo |
| --- | --- |
| Unidades | Cadastros de unidades fictícias |
| Profissionais | Registros pseudônimos sem dados de pessoa |
| Equipes | Vínculos de equipes fictícias |
| Atendimentos | Eventos sintéticos sem informação clínica |

`total = sucesso + erros`. `prepared` conta somente registros que passaram na validação. `ENVIADO` é estado intermediário, nunca resultado final. A distribuição por serviço reconcilia com o total. Período ilustrativo: setembro de 2026.
