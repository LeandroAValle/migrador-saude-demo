# Privacidade e segurança

- O repositório contém código novo e dados sintéticos; não contém código, banco, credenciais, consultas municipais ou logs do sistema privado.
- Não há conexão com API externa ou banco de saúde.
- O guard demonstrativo bloqueia qualquer ambiente diferente de `sandbox` antes da simulação.
- O snapshot JSON foi criado para publicação; não deve ser substituído por exportação real.
- A interface mostra dados como texto, sem interpretar conteúdo do snapshot como HTML executável.
- Este projeto não deve ser usado para migração operacional ou decisão sobre pessoas.
