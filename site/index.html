SOBRE O PROJETO

Segurança, estado e evidência em cada etapa.

Este demo independente traduz conceitos do Migrador Saúde v2 em uma experiência pública, sem expor o sistema operacional. O projeto original usa Python/FastAPI e React/TypeScript e permanece privado. Aqui, um pipeline Python offline gera resultados sintéticos para um painel estático. A escrita é bloqueada fora do sandbox até no simulador.
